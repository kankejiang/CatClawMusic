唱片浮岛

把底部两栏当成一块浮在内容之上的玻璃岛，而不是两条贴底横带。三个抓手：封面溢出的黑胶、跟着封面变色的环境光、只展开一个标签的底栏。

① 黑胶从封面后面探出来

封面左移、黑胶圆盘从右侧露出约 8px，缓慢旋转。只用了一个圆形 + 环形纹理，成本极低，但一眼就知道“在放歌”。

② 环境光跟着封面走

迷你播放器下面垫一层 blur(26px) 的渐变辉光，取封面的主色。玻璃立刻不再是一块“死灰”，而是和当前歌曲产生关系。

③ 环形进度 + 均衡器

播放键外圈用 conic-gradient 画进度环——比底部的细线更醒目、也更省空间。标题右侧三条跳动的柱子表示正在播放，替代“播放/暂停”的语义重复。

④ 底栏只展开一个标签

选中项展开成“图标 + 文字”的粉色药丸（带内发光），其余三项只留图标。既保证你知道自己在哪，又不会四项都挂文字显得碎。

⑤ 玻璃的厚度

每一块玻璃都是：inset 0 1px 0 rgba(255,255,255,.22) 顶部高光 + inset 0 -1px 0 rgba(0,0,0,.34) 底部暗边 + 外投影。这三层缺一不可，单靠模糊是没有厚度的。

落地成本

  • 迷你播放器：重写一个 composable，黑胶是 Canvas 画环 + infiniteRepeatable 旋转；环境光是 Box + blur 修饰符。
  • 底栏：现有的 BarGlass 不动，只把选中项换成 AnimatedContent / animateDpAsState 的展开药丸。
  • 进度环：Canvas 的 drawArc，参数直接接 positionMs / durationMs。
