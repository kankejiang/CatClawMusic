🐾 猫爪音乐 · 萌系改造方向对比

三套方向、同一组页面(音乐库主页 / 播放页 / 发现页),直接在浏览器打开对比。
每个文件底部附该方向的组件样例与设计令牌(色板/圆角/字体/动效)。

方向 A · 轻

猫爪品牌统一

深紫夜空毛玻璃布局不动,主色换成品牌猫爪粉,tab 爪印化,启动链路接入真 logo。风险最低、见效最快,但整体仍是"精致玻璃播放器"。

 方向 B · 中(推荐)

奶油软萌全面改造

奶油白浅色体系 + 樱粉主色 + 圆体标题(站酷快乐体)+ 大圆角软阴影 + Q 弹动效 + 萌系空状态。最能兑现"萌系"承诺,深色模式做暖紫黑"夜猫模式"。

 方向 C · 重

完整猫娘人格化

B 的全部 + Yuki 全场景常驻陪聊、猫耳机身(圆角猫耳)、爪印进度条/播放键/收藏、喵口癖文案全面化。品牌人格最强,工作量最大,需新增插画素材。
对比建议:三套并排打开,只看"第 1 眼感觉"——不看细节,问自己"这个 app 我会想点开吗"。
选定方向后,实施按「令牌层 → 启动链路 → 关键页面 → 全量」分批进行。
