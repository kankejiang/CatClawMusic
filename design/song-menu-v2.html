歌曲菜单 · 设计稿 v2

旧版的问题：所有操作都是同样的圆角彩块 + 文字，一眼看过去全是"同款格子"，没有主次，也没有状态感。

这版改了什么

  • 三级层次：头部（这是哪首）→ 快捷胶囊（最常做的三件事）→ 分组列表（其余）。旧版把 11 行平铺，没有"主次"。
  • 胶囊承载主操作：收藏 / 歌曲信息 / 分享做成大按钮，收藏态用粉色高亮 + 实心心，一眼可见。
  • 去掉了「下一首播放」：正在播放的这首再点它没有意义（那是队列里其它曲的动作），这个位置换成了歌曲信息 —— 播着歌最常想确认的就是码率/格式/来源。
  • 状态改用控件：桌面歌词用真正的开关，其它行用尾部文字（关闭 / 3 个歌单），不再靠"关"这个孤零零的字。
  • 信息前移：查看歌手/专辑把目标名直接写在行尾（David Garrett / Martynas），点之前就知道会去哪。
  • 更轻的质感：30dp 圆角、发丝分隔线（7% 白）、图标底色 7% 白、毛玻璃面板 —— 和播放页的雾化背景是一套语言。
  • 撤销"图标彩块"：旧版每行一块高饱和色，颜色互相打架；这版只有一处强调色（粉），其余全是中性灰白。

落地到 Compose

  • 所有尺寸/颜色都能直接映射成 dp 与 palette 字段（粉 = palette.primary）。
  • 开关、胶囊、列表行都是独立 composable，可复用到歌单/专辑菜单。
  • 动效：面板 tween(420, easing = CubicBezierEasing(.22,1,.36,1)) 上滑，胶囊 hover/press 位移 1dp。
