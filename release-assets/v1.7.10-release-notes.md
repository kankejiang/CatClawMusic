# v1.7.10 — 主题系统重构 + Windows 视觉打磨 + 封面解析修复

## 摘要

本次更新重构了主题系统（10 套代码绘制的渐变背景），并对 Windows 桌面端的窗口外观、播放页动效与明暗主题适配做了系统性打磨。同时修复了两个困扰已久的封面问题：部分本地音乐在播放页回退默认封面、以及播放页封面分辨率偏低。Android 与 Windows 双端同步发布。

---

## 新增与改进

### 🎨 主题系统重构
- 新增 10 套代码绘制的渐变背景设计，全部由 Win2D/Canvas 运行时绘制，移除所有内置背景图片，包体更小。
- 主题背景、光晕与深浅模式全面联动，明暗两套配色均按当前主题主色派生。
- 修复浅色模式下启动时窗口顶部仍为深色的问题（DI 解析静默降级导致标题栏永远走深色分支）。

### 🪟 Windows 窗口与视觉打磨
- 沉浸式标题栏：移除系统标题栏黑条，窗口内容铺满顶部，系统按钮浮于右上角并跟随主题着色。
- 修复窗口最外圈在浅色模式下出现的"白边"（DWM 边框色改为不绘制，由内容自然贴边）。
- 播放页雾面动态背景专门适配 PC：分辨率提升至 512、动画常驻（不再随播放状态停止）、旋转改为有界振荡彻底消除角部漏底色，主舞台改为透出真正的雾面动态背景。
- 排序/筛选 chip（标题/艺术家/专辑/时长等）改为主题感知，浅色模式下不再与背景融为一体看不清。
- 播放器进度条/音量条拇指与已播进度改用当前主题主色，浅色模式下不再是难看的黑点。
- About 页：修复 Yuki 头像不显示（资源名漏 `.png` 后缀），按钮列表改为双列布局，头像压缩至 148KB（包体减小约 4.8MB）。
- 播放页移除装饰性的极光大圆，界面更干净。

### 🎤 歌词与播放
- 修复前后台切换后歌词高亮漂移的问题。
- 新增译文歌词支持。

### 🖼️ 封面解析修复
- 放宽封面文件校验（仅校验文件头 magic 与尺寸，不再苛求 JPEG/PNG/GIF 文件尾严格收尾）——修复部分本地音乐在播放页回退默认封面的问题（发现页能显示而播放页不显示的根源）。
- 修复播放页封面分辨率偏低：封面尺寸桶曾被 300px 缩略图"冒充"为 1000px 缓存，现已增加实际尺寸校验并在发现过小缓存时自动从音频文件重新提取全分辨率封面。

---

## 修复

- 浅色模式启动后窗口顶部仍是黑色的问题。
- 浅色模式下窗口外圈白边。
- 播放页雾面动态背景不随封面变色、静止不动的问题。
- 排序/筛选 chip 浅色模式下看不清。
- About 页 Yuki 头像不显示。
- 部分本地音乐播放页封面不显示（回退默认封面）。
- 播放页封面分辨率低（尺寸桶被缩略图污染）。
- 前后台切换后歌词高亮漂移。
