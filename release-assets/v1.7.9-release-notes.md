# v1.7.9 — Windows 歌词页重写 + 横竖屏优化 + 安装程序

## 摘要

本次更新重点重构了 Windows 桌面端的歌词体验，并针对横竖屏切换、网络歌曲元数据补全等场景做了大量打磨。Android 端同步获得安装包，Windows 端首次提供单文件安装程序，方便直接分发。

---

## 新增与改进

### 🎤 Windows 歌词页全面重写
- 采用「静态堆叠 + 平移滚动」机制，滚动与高亮动画更平滑、更跟手。
- 当前播放行视觉放大 50%，并始终固定在视口第 3 行，首尾不再夹紧。
- 非当前行加入高斯模糊景深效果，焦点更集中。
- 歌词区域改用系统级 Acrylic 毛玻璃背景，与 Windows 原生视觉风格融合。
- 统一已唱行与未唱行配色，修复整列不向上滚动的问题。

### 📱 横竖屏体验优化
- 优化播放页与桌面页的横屏布局，切换更自然。
- 适配多平台安全区（SafeArea），避免内容被刘海、圆角或系统栏遮挡。
- 播放页封面在横竖屏切换后自动重载高分辨率资源，避免模糊。

### 🌐 网络歌曲元数据补全
- 网络音乐下载与元数据补齐过程新增前台进度提示，并支持取消。
- 修复部分 M4A（非 faststart，moov 位于文件尾部）封面已补但艺术家/专辑仍显示「未知」的问题。

### 📦 构建与发布流程
- 新增 `build-win-release.ps1`：一键完成 Windows Release 构建 + Inno Setup 安装程序打包。
- 新增 `build-win-setup.iss`：中文向导式安装程序脚本，含桌面快捷方式与卸载入口。
- Windows Release 输出移除 pdb/xml 调试符号，目录更干净（多语言卫星程序集完整保留）。
- `global.json` 的 `rollForward` 从 `latestMajor` 改为 `latestFeature`，锁定 .NET 10，避免滚到预览版 SDK 导致构建失败。
- 修复 `App.generated.cs` 与自动生成的 `App.g.i.cs` 冲突导致的编译错误。

---

## 修复

- Windows 歌词页非当前行整片消失的问题。
- 已唱/未唱行高斯模糊不可见的问题。
- 网络歌曲元数据补全过程中无法取消的问题。
- 横竖屏切换后播放页封面可能模糊的问题。
