# 猫爪音乐 v1.8.6 更新日志

> 自 v1.8.5 以来共 28 个提交，涵盖歌词来源模式、网易云风格底部抽屉、歌曲列表交互重构与多项修复。

## ✨ 新增功能

- **歌词来源模式**（本次重点）
  - 歌词设置新增"来源模式"三选一：**自动**（优先外挂 `.lrc`，无外挂读内嵌，都没有回退网络歌词）/ **内嵌**（只看音频文件内嵌歌词）/ **外挂**（只看同名 `.lrc/.ttml` 文件）
  - 内嵌/外挂模式严格跳过网络歌词链路（Navidrome/网易云/插件），没有指定来源即显示"暂无歌词"
  - 切换后立即重新加载当前歌曲歌词，立即生效
  - 全屏歌词页 ⚙ 与 Windows 播放页"歌词设置"均可切换

- **网易云风格底部抽屉**
  - 歌曲长按菜单升级为底部抽屉（Android）：保留歌曲信息卡与核心操作，半屏高度 + 下滑关闭手势
  - 抽屉高度自适应屏幕（70% 屏高），高分屏不再过矮

- **私人漫游模式选择抽屉**
  - 3 个推荐模式 + 36 个场景，AppBottomSheet 半屏展示

- **歌曲列表行交互重构**
  - 歌曲行改用 Button：原生按压高亮反馈
  - 长按入口从"⋮"扩展为整行，长按弹菜单更稳定

## 🛠 修复

- **Android**
  - 修复进入本地音乐页闪退（移除歌曲行模板内联 VisualStateManager）
  - 修复二次进入本地音乐封面消失（列表缓存刷新路径补封面解析）
  - 修复长按歌曲菜单不可见（移除 ContextMenuPopup 卡片阴影）
  - 修复长按菜单底部越界（布局完成后按真实尺寸重新约束弹窗位置）
  - 修复登录导航在插件 Push 栈上 GoToAsync 空引用

- **AI 对话**
  - 支持中断 AI 回复，重构工具消息裁剪逻辑

- **构建**
  - 移除测试项目及相关测试代码，清理解决方案残留引用（修复构建失败）
