# 猫爪音乐 v1.8.9 更新日志

> 自 v1.8.8 以来共 43 个提交，涵盖 Windows 桌面端晨雾框架重构、真毛玻璃升级、横屏适配与稳定性修复。

## ✨ 新增功能

- **Windows 桌面端晨雾框架重构**
  - 桌面壳改用晨雾框架布局，与安卓横屏 DesktopMainPage 一致（侧栏浮层卡 + 顶栏 + 播放条浮层卡）
  - 侧栏与底部播放条改为真毛玻璃浮层卡，圆角 16 + 导航主题色渐变高亮
  - 顶栏整行作窗口拖动区，移除重复按钮
  - 设置入口从侧栏底部迁移到发现页右上角齿轮

- **真毛玻璃升级**
  - 底部导航栏 / 迷你播放器 / 侧栏改用 Vitrum 真毛玻璃，透出下层真实内容
  - 毛玻璃模糊半径 24dp 提升至 60dp，雾感更强
  - 桌面玻璃卡片配色跟随主题色动态变化

- **侧栏视觉优化**
  - 浅色模式未选中项用主题色文字 / 图标，选中项白色文字 + 白色图标
  - 侧栏导航图标改用竖屏版 SVG 图标

## 🛠 修复

- **Windows 桌面端**
  - 修复内容区被上层占位 Grid 拦截导致无法点击 / 滚动
  - 修复底部播放器控件被毛玻璃层遮挡不可见
  - 修复底部播放器进度条轨道不可见与长度过短
  - 修复发现页右上角设置齿轮打不开设置页
  - 修复内容区空白与毛玻璃变实心色块

- **稳定性**
  - 全部 CollectionView 设置 KeepScrollOffset，消除启动时 StartBringItemIntoView stowed 异常崩溃
  - Windows 启动时挂 WinUI UnhandledException 钩子，stowed 异常落盘 crash_xaml.log
  - 横竖屏切换白屏——延迟到旋转完成后再切换 Shell 根页面
  - GlobalBackgroundService 用 #if ANDROID 包裹，修复 Windows 编译错误

- **横屏适配**
  - 推荐专辑改为横屏单行左右滑动
  - 横屏发现页卡片按可视高度分档自适应
  - 修复横屏发现页推荐艺人 / 专辑被底部播放条遮挡

- **发现页**
  - 每日推荐 / 推荐艺人改用原地更新集合，修复 WinUI 下不渲染
  - 迷你播放器遮挡推荐艺人时动态预留滚动内容底部空间

## 📦 安装包

- Android: com.catclaw.music-Signed.apk（versionCode 66）
