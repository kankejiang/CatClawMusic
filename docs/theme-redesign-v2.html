📋 设计变更说明

  • 底部不再纯黑：TabBarGlassTint 从 #000000 → #1A1830，与页面底色统一
  • 渐变穿透到底：PageBackgroundBrush 底部从 #3A2B6E 改为 U 型回弹，底部反而比中段稍亮
  • 毛玻璃暗化减半：DimAmount 0.65 → 0.40，TintOpacity 0.25 → 0.18
  • 色温偏暖：所有深色基底从冷黑(#080B1A)调整为带紫调的暖黑(#12101F)
  • 层级可读性：背景四层(base/elevated/surface/hover)每层 ΔL≈4%，肉眼可区分但不刺眼
  • v2 渐变特色：底部颜色回弹（比中段更亮），消除"越往下越黑"的沉闷感
