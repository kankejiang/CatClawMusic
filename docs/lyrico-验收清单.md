## 环境准备

```powershell
$adb = "C:\Users\lvjin\AppData\Local\Android\Sdk\platform-tools\adb.exe"
& $adb devices                                   # 确认设备在线
& $adb shell svc power stayon true               # 防休眠（否则 uiautomator 交互全是空）
& $adb shell input keyevent 224                  # 唤醒
& $adb shell wm dismiss-keyguard                 # 解锁
& $adb shell settings put system accelerometer_rotation 0
& $adb shell settings put system user_rotation 0 # 固定竖屏（横屏布局不同，坐标会错）
```

安装：`adb install -r app/build/outputs/apk/debug/app-debug.apk`
（MIUI 限制新包名安装，本项目包名已存在，`-r` 可覆盖更新）

**已知环境坑**：
- 设备会进入 Dozing，`screencap` 返回空文件 → 交互前必须确认截图非空
- install 后旧的 Activity 栈会被复用，`onCreate` 不一定重新执行 →
  需要 `am force-stop` 再 `am start`
- 网络曾出现应用进程 DNS 全部失败（`No address associated with hostname`），
  联网项验收前先确认网络正常

## 已知遗留问题

1. **ReplayGain 未实现** —— 依赖 ffmpeg + ebur128 两个未移植的原生库。
   当前在界面上选中会提示「会全部跳过」，处理时返回 Skipped 并说明原因，不会静默失败。

2. **`:data` 模块缺 kotlinx-serialization 编译插件** —— `BackupJson` / `ChatMemoryStore`
   用了 `@Serializable` 但模块没应用插件，序列化器实际未生成。
   这**不属于本次移植范围**，但会影响「备份恢复」与「AI 聊天记忆」，建议单独修。

3. **Lyrico 的播放器 / 桌面歌词 / 双皮肤 / Pro 页未移植** —— 按既定范围排除
   （复用本工程既有播放器与视觉语言）。
