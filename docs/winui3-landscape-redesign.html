与上一版的差别：侧栏从 110px 收到 99px 且上下留 16（非通栏）；卡片圆角 20、5% 白面； 入口恢复彩色渐变（Android 横屏最显眼的特征，上一版被我做成了灰）；播放器改回 整条 47px 左让侧栏； 标题区加回 竖分隔线 + 问候语横排。

WinUI 落地：MainWindow.xaml 用 Grid ColumnDefinitions="133,*"，左列放自绘 Border 侧栏（Margin="16,16,0,16"、CornerRadius="16"）； Tokens.xaml 换色 #F56FA0→#8FA3CC；新增 QuickTileStyle（彩色 LinearGradientBrush + 1px 白描边）。
